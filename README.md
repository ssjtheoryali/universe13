# Universe 13: Battle Clash (web)

Godot web build of Universe 13: the HQ lobby, Battle Mode, Combo Lab. Served by GitHub Pages at
https://ssjtheoryali.github.io/universe13/

`index.pck` is split into `index.pck.NNN` parts (git can't hold files over 100 MB); `u13-pack-loader.js` streams them
back together in the browser. Built by `tools/web/pages/split_pack.mjs` in the u13-power-royale repo.
Story: https://ssjtheoryali.github.io/universe13-story/ · Classic browser game: https://ssjtheoryali.github.io/universe13-classic/
